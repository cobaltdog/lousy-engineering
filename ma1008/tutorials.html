    #Tutorial 1 (Python Basics)

    #Question 1

    Name the two levels of languages that are normally involved in the programming process. What are they for? What is the relationship between them.

    • Machine language (encoded in binary format)
    • High-level programming language

    A program is written in a high-level programming language by the user, which is then translated into machine language that the computer can read and be instructed to
    perform operations as intended by the program.

    #Question 2

    What is a compiled language? What is an interpreter? Give two examples for each.

    A compiled language requires the entire program be compiled first before the computer executes the program. A compiler reads and translates the high-level programming language into machine language in an executable file, which the computer runs and generates an output.

    Examples: C, C++, Java

    An interpreter reads and translates the high-level programming language into machine language line by line — executing a line before proceeding to the next one.

    Examples: Python, JavaScript, R

    #Question 3

    How does a computer represent numbers?
    How does it represent non-numeric data such as letters and colors?

    A computer represents numbers in binary format.

    Letters can be represented by assigning bits to the letters.

    Colors can be represented by assigning values to Red, Green, Blue.

    #Tutorial 7 (Functions)

    #Question 1

    List the parts in a function definition and explain the purpose of each part.

    • Keyword def signifies the start of a function definition
    • Function name for identifying and calling it (follows the same rules as variables)
    • Parameters in parenthesis are inputs to function and are optional, followed by a :
    • Function body contains the code that performs operations required

    #Question 2

    Give three reasons why functions are useful.

    • Abstraction — working at a higher level, hiding local details
    • Reusable — function can be used anywhere to solve the same problem
    • Sharing — function can be shared and used in other programs instead of rewriting it
    • Security — functions can be made more secure than local code as it is self-contained
    • Simplification and readability — a consequence of abstraction, removing distractions
    • Divide and conquer problem solving — provide solution to one part of a big problem

    #Tutorial 8 (More on Functions)

    #Question 1

    Where in a program can a function be defined?

    Can functions be defined inside a function?

    A function can be defined anywhere where an executable statement is expected.

    Nested functions can be defined anywhere where executable statement are expected.

    What is an optional parameter in a function and how is it created?

    How many optional parameters can a function have?

    Can there be a mix of optional and non-optional parameters?

    A optional parameter (default/named/keyword) is followed by an equal sign and an expression that gives its default value while a positional parameter is a name which
    is not followed by an equal sign and a default value.

    An optional parameter is one where, if the parameter is not supplied in a function call, it assumes a default value. This default value is given in the function definition where the parameter appears with an assignment to the default value.

    There is no limit to the number of default parameters, one can specify as many as required. There can be a mix, but non-optional parameters should come first.

    #Tutorial 9 (Files & Exception Handling)

    #Question 1

    Explain what is a binary file and a text file.

    What are the key differences between them?

    A binary file contains information that is encoded based on specific standards.
    A text file contains information in the form of ASCII or Unicode characters.

    Binary files are not human readable, but are smaller in size — storage efficient.
    Text files are generally human readable, but are larger in size than binary files.
    ASCII characters take up 8 bits or 1 byte. Unicode characters take up 32 bits or 4 bytes.
