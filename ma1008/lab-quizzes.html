    #Question A

    A population survey divides people into four age groups:

    • Senior: 60 years and above
    • Adult: between 21 and 59, inclusive
    • Youth: between 11 and 20, inclusive
    • Child: less than 11 years old

    Write a program that reads in the ages of people. Keep on reading until a negative age is given, at which point you should terminate the input. Your program should reject any age higher than 115, and require the user to provide it again.

    After the input, print the total number of people and the number in each category. At the
    end, also print the average age of the people and the group this average belongs to.

    The first line of the program must be a comment line with name and group number.

    #Question 9

    An encryption scheme picks alternate characters in a given string, starting from the first,
    and then converts every letter of either case to the next letter of the same case in the alphabet, with the last letter “z” becoming “a”, and “Z” becoming “A”. All other
    characters remain unchanged.

    Hence, “AB_yz_12” would first yield “A_z1”, which is encrypted into “B_a1”.

    #Question C

    The data in the file weight.txt contains rows of numbers separated by commas. Each row
    is terminated by a newline character. Occasionally, there are typing errors such that the numbers are not numbers.

    The numbers are the weights of male adults. These weights are divided into 3 categories:

    • Overweight: 85kg or more
    • Good weight: less than 85kg and more than 55kg
    • Underweight: 55kg or less

    Provide a function that returns the weight category given a string containing a weight.
    Write a program that calls the function, does the count and prints out the four counts.

    #Question D

    Write a program that opens the file, reads in each line, evaluates and prints the result.
    Your program should include at least one function that takes the three components of
    an expression as arguments and returns the value of the expression.

    #Question G

    The file ExchangeRate.txt contains exchange rate of different currencies against SGD1.
    Each line contains three items: short currency name (three letters), exchange rate, full currency name, separated by commas. The exchange rate is a floating point number
    and the other two are strings.

    Write a function called currencyRate that takes a line from the file as an input parameter and returns the three fields in the line as a list with three items [string, float, string].

    Write another function called exchangeAmount which takes the following parameters:

    • amount: the amount to be converted
    • currency: the currency to convert to or from
    • mode: a value indicating converting to or from, and defaulted to “to”

    Write a program that asks for:

    (1) the currency concerned using three-letter short currency name

    (2) the amount to be converted

    (3) whether to or from the currency

    It then prints the result using the full name of the currency.
