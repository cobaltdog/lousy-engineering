    Response and Stability

    #Time Response

    Time response of a system consists of:

    • Transient response — period between initial state and final state
    • Steady-state response — manner in which system output behaves as t→∞

    A system’s response can be written as,

    💡
    c(t)=ctr​(t)+css​(t)

    Transient response of a system determines the deviation between the output and
    the input before the steady state is reached. Once steady state is reached, if the
    steady state response does not agree with the steady state of the input (desired
    response), a steady state error occurs.

    #1st-Order System

    Consider a first-order system with input R(s) and output C(s).

    Closed loop transfer function of the above system is given by,

    R(s)C(s)​=1+G(s)⋅H(s)G(s)​

    R(s)C(s)​=1+1/(τs)1/(τs)​

    R(s)C(s)​=τs+11​

    where τ is the time constant of the response

    #Unit Step Input

    If the input is a unit step, where R(s)=s1​, the response is,

    C(s)=s1​⋅τs+11​

    C(s)=s(τs+1)1​

    C(s)=s1​−τs+1τ​

    C(s)=s1​−s+1/τ1​

    Performing inverse Laplace transform, the response is,

    💡
    c(t)=1−e−t/τ

    Settling time, defined as the time for the response to reach and stay within 2% of
    its final value, is obtained by substituting c(t)=0.98 into the response equation.

    💡
    Ts​=4τ

    #Unit Ramp Input

    If the input is a unit ramp, where R(s)=s21​, the response is,

    C(s)=s21​⋅τs+11​

    C(s)=s2(τs+1)1​

    C(s)=s21​−sτ​+τs+1τ2​

    C(s)=s21​−sτ​+τ(s+1/τ1​)

    Performing inverse Laplace transform, the response is,

    💡
    c(t)=t−τ+τe−t/τ

    Error in the response signal is then,

    e(t)=r(t)−c(t)

    e(t)=t−(t−τ+τe−t/τ)

    e(t)=τ−τe−t/τ

    💡
    e(t)=τ(1−e−t/τ)

    Note that r(t) is the inverse Laplace transform of the input R(s).

    #Unit Impulse Input

    If the input is a unit impulse, where R(s)=1, the response is,

    C(s)=1⋅τs+11​

    C(s)=s+1/τ1/τ​

    Performing inverse Laplace transform, the response is,

    💡
    c(t)=τ1​e−t/τ

    #2nd-Order System

    A general second-order transfer function is represented as,

    💡
    G(s)=s2+2ζωn​s+ωn​2ωn​2​

    where ωn​ is the natural frequency of oscillation of a system without damping,
    and     ζ is the damping ratio which is independent of time scale (sec, hrs, etc.)

    Solving for the roots of the denominator,

    💡
    s1,2​=−ζωn​±ωn​ζ2−1​

    For an undamped or underdamped system, the second term is imaginary.

    s1,2​=−ζωn​±jωn​1−ζ2​

    s1,2​=−ζωn​±jωd​

    where ωd​ is the damping frequency

    A second-order system exhibits a wide range of responses. It can display
    characteristics similar to a first-order system, or display damped or pure
    oscillations for its transient response.

    Response to unit step input for an undamped system where ζ=0.

    💡
    c(t)=Acos(ω1​t−ϕ)

    Two imaginary poles at s1,2​=±jω1​.

    Response to unit step input for an underdamped system where 0<ζ<1.

    💡
    c(t)=Ae−ζωn​tcos(ωd​t−ϕ)

    Two complex poles at s1,2​=−ζωn​±jωd​.

    Response to unit step input for a critically damped system where ζ=1.

    💡
    c(t)=K1​e−ζω1​t+K2​e−ζω1​t

    Two real poles at s=−ζω1​.

    Response to unit step input for an overdamped system where ζ>1.

    💡
    c(t)=K1​e−ζω1​t+K2​e−ζω2​t

    Two real poles at s1​=−ζω1​ and s2​=−ζω2​.

    The responses of a second-order system for different inputs are,

    💡
    c step​=c(t)
    💡
    c ramp​=∫0t​c(t) dt
    💡
    c parabolic​=∫0t​∫0t​c(t) dtdt
    💡
    c impulse​=dtd​c(t)

    Laplace transform of a unit parabolic input is R(s)=s31​.

    #Underdamped Second-Order System

    Consider a unit step input to an underdamped second-order system.
    We get the response curve by plotting the response c(t) against time.

    Rise time is defined as the time required
    to go from 0.1 to 0.9 of the final value.

    💡
    tr​=ωn​1−ζ2​β​=ωd​π−β​

    where β=cos−1ζ

    Peak time is defined as the time required to reach the first (maximum) peak.

    💡
    tp​=ωn​1−ζ2​π​=ωd​π​

    Percent overshoot is defined as the amount of overshoot at the peak time.

    💡
    Mp​=e1−ζ2​−ζπ​

    Settling time to reach and stay within 2% or 5% of the final value is,

    💡
    ts(2%)​=ζωn​4​

    Occurs at t=4τ.

    💡
    ts(5%)​=ζωn​3​

    Occurs at t=3τ.

    Steady state error of the system is,

    💡
    ess​=1−css​

    #System Stability

    Stability of a system:

    • System is stable if transient response approaches zero as t→∞
    • System is unstable if transient response approaches infinity as t→∞
    • System is marginally stable if transient response neither decays or grows

      A marginally stable system can have an output that remains constant or oscillates.

    #Routh-Hurwitz Criterion

    The Routh-Hurwitz criterion allows us to determine the stability of a system.

    • Number of sign changes in the first column indicates the number of roots
      of the denominator that are located in the right half-plane of the pole plot
    • System is stable if there is no sign changes in the first column

    #Special Cases of Criterion

    Special cases of the Routh table:

    • A zero only in the first column of a row
    • An entire row that consists of zeroes

    #Zero Only in the First Column

    If the first element of a row is zero:

    • Replace the zero with ε
    • ε is allowed to approach zero from either the positive or negative side
    • Determinants are expressed in terms of ε and signs of each element is determined

    If ε is chosen to be positive:

    • 1st sign change from the s3 row to the s2 row
    • 2nd sign change from the s2 row to the s1 row
    • System is unstable and has two roots in the right half-plane

    If ε is chosen to be negative:

    • 1st sign change from the s4 row to the s3 row
    • 2nd sign change from the s3 row to the s2 row
    • System is unstable and has two roots in the right half-plane

    #Entire Row is Zero

    Consider a closed-loop transfer function,

    T.F.=s5+7s4+6s3+42s2+8s+5610​

    Forming the Routh table for the denominator, the 3rd row becomes entirely zeroes.
    We form an auxiliary polynomial using elements in the row above it as coefficients.

    Thus, we form the polynomial using elements in the 2nd row.

    P(s)=s4+6s2+8

    Differentiating the above with respect to s, we obtain,

    dsdP(s)​=4s3+12s+0

    The coefficients of the differential are then used to replace the zeroes in the 3rd row.
    The remaining elements are formed in a straightforward manner in the standard way.
