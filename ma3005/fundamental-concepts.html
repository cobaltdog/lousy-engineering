    MA3005 · CONTROL THEORY

    Fundamental Concepts

    #System Configurations

    A control system consists of subsystems and processes assembled for the purpose
    of obtaining a desired output with desired performance, given a specified input.

    Types of control systems:

    • Open loop system
    • Closed loop system

    Description of open loop system:

    • Input transducer converts the form of the input to that used by the controller
    • Cannot compensate for any disturbances that add to controller’s driving signal
    • Corrupted output is not fed back for comparison with the input
    • Output has no effect on the control action

    Description of closed loop system:

    • Output transducer measures the output response to detect disturbances
    • Compares output response to the input at the summing junction
    • Difference between the two responses is the actuating error
    • System drives the plant to make a correction

    #Laplace Transformation

    The Laplace transform is defined as,

    💡
    L{f(t)}=F(s)=∫0∞​f(t)e−st dt

    #Partial Fraction Expansion

    To obtain the inverse Laplace transform of a complicated function, we can convert
    the function to a sum of simpler terms for which we know the Laplace transform
    of each term.

    #Transfer Function

    The transfer function of a linear, time-invariant, differential equation system is defined as the ratio of the Laplace transform of the output to the Laplace transform of the input, under the assumption that all initial conditions are zero.

    💡
    G(s)=L{Input}L{Output}​

    Comments on transfer function:

    1. Mathematical model in that it is an operational method of expressing the
      differential equation that relates the output variable to the input variable.
    2. Property of a system itself, independent of magnitude and nature of input.
    3. If transfer function is known, output can be studied for various forms of inputs.
    4. If transfer function is unknown, it may be established experimentally
      by introducing known inputs and studying the output of the system.

    #Open-Loop Transfer Function

    Open-loop transfer function is defined as,

    💡
    O/L  T.F.=E(s)B(s)​=G(s)⋅H(s)

    Ratio of the feedback signal to the actuating signal.

    #Closed-Loop Transfer Function

    The output and input signals are related by,

    E(s)=R(s)−B(s)

    E(s)=R(s)−H(s)⋅C(s)

    The output signal is obtained from,

    C(s)=G(s)⋅E(s)

    C(s)=G(s)⋅[R(s)−H(s)⋅C(s)]

    C(s)=G(s)⋅R(s)−G(s)⋅H(s)⋅C(s)

    Closed-loop transfer function is defined as,

    💡
    C/L  T.F.=R(s)C(s)​=1+G(s)⋅H(s)G(s)​

    #Closed-Loop System with Disturbance

    Multiple inputs in a system:

    • Each input can be treated independently of each other
    • Each output is computed by assuming all other inputs are zero
    • Outputs corresponding to each input are added together to give complete output

    #Block Diagrams

    Complicated systems are represented by the interconnection of many sub-systems.
    Since the response of a single transfer function can be computed, it is useful to
    represent multiple sub-systems as a single transfer function — reduction.

    #Cascade Form

    If transfer functions are connected in series,

    💡
    Ge​(s)=G3​(s)⋅G2​(s)⋅G1​(s)

    where subscript e represents the equivalent transfer function

    #Parallel Form

    If transfer functions are connected in parallel,

    💡
    Ge​(s)=±G1​(s)±G2​(s)±G3​(s)

    whereby the sign depends on the summing junction

    #Feedback Form

    For a closed-loop system, the equivalent transfer function is,

    💡
    Ge​(s)=1±G(s)⋅H(s)G(s)​

    Feedback signal subtracted from actual signal → “+” sign
    Feedback signal added to actual signal → “-” sign
