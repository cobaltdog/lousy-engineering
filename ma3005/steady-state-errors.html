    Steady-State Errors

    #Unity Feedback Systems

    Consider a unity feedback control system, where H(s)=1.
    Error between the input and output is E(s)=R(s)−C(s).
    From the block diagram, we also know that C(s)=E(s)⋅G(s).

    Substituting C(s) into E(s), we get,

    💡
    E(s)=1+G(s)R(s)​

    Applying final value theorem, general equation for steady-state error is,

    💡
    ess​=s→0lim​ 1+G(s)s⋅R(s)​

    By substituting different inputs, we can determine the steady-state error characteristics.

    #Example 1

    Laplace transform of inputs,

    L{5}=s5​

    L{5t}=s25​

    L{5t2}=s310​

    From Laplace transform table,

    L{tn}=sn+1n!​

    Steady-state error of unit step input,

    ess,step​=s→0lim​ 1+G(s)s(5/s)​

    ess,step​=s→0lim​ 1+(s+3)(s+4)120(s+2)​5​

    ess,step​=1+205​

    ess,step​=215​

    Steady-state error of unit ramp input,

    ess,ramp​=s→0lim​ 1+G(s)s(5/s2)​

    ess,ramp​=s→0lim​ s+s⋅G(s)5​

    ess,ramp​=s→0lim​ s+(s+3)(s+4)120s(s+2)​5​

    ess,ramp​=∞

    Steady-state error of unit parabolic input,

    ess,para​=s→0lim​ 1+G(s)s(10/s3)​

    ess,para​=s→0lim​ s2+s2⋅G(s)10​

    ess,para​=s→0lim​ s2+(s+3)(s+4)120s2(s+2)​10​

    ess,para​=∞

    #Example 2

    Steady-state error of unit step input,

    ess,step​=s→0lim​ 1+G(s)s(5/s)​

    ess,step​=s→0lim​ 1+s(s+3)(s+4)100(s+2)(s+6)​5​

    ess,step​=1+∞5​

    ess,step​=0

    Steady-state error of unit ramp input,

    ess,ramp​=s→0lim​ 1+G(s)s(5/s2)​

    ess,ramp​=s→0lim​ s+s⋅G(s)5​

    ess,ramp​=s→0lim​ s+(s+3)(s+4)100(s+2)(s+6)​5​

    ess,ramp​=1005​

    ess,ramp​=201​

    Steady-state error of unit parabolic input,

    ess,para​=s→0lim​ 1+G(s)s(10/s3)​

    ess,para​=s→0lim​ s2+s2⋅G(s)10​

    ess,para​=s→0lim​ s2+(s+3)(s+4)100s(s+2)(s+6)​10​

    ess,para​=∞

    #Static Error Constants

    Steady-state error for a unit step input, where R(s)=s1​,

    💡
    ess​=s→0lim​ 1+G(s)1​=1+s→0lim​G(s)1​=1+Kp​1​

    where Kp​ is the static position error constant

    Steady-state error for a unit ramp input, where R(s)=s21​,

    💡
    ess​=s→0lim​ 1+G(s)1/s​=s→0lim​ s⋅G(s)1​=Kv​1​

    where Kv​ is the static velocity error constant

    Steady-state error for a unit parabolic input, where R(s)=s31​,

    💡
    ess​=s→0lim​ 1+G(s)1/s2​=s→0lim​ s2⋅G(s)1​=Ka​1​

    where Ka​ is the static acceleration error constant

    If the input level is equal to the system level, the error has a finite value.
    If the input level is higher than the system level, the error is infinite.
    If the input level is lower than the system level, the error is zero.
