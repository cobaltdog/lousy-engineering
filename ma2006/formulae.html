    #Linear Algebra

    #System of Linear Algebraic Equations

    A system of N linear algebraic equations in N unknowns is in the form:

    a11​x1​+a12​x2​+a13​x3​+...+a1N​xN​=b1​a21​x1​+a22​x2​+a23​x3​+...+a2N​xN​=b2​⋮aN1​x1​+aN2​x2​+aN3​x3​+...+aNN​xN​=bN​

    where aij​ is the coefficient of the unknown xj​ and bi​ is the constant term

    Consider a single linear algebraic equation c1​x1​+c2​x2​+...+cN​xN​=dN​.

    ​x1​x2​⋮xN​​​=​α1​α2​⋮αN​​​

    is a solution of the equation if LHS=RHS after substituting the values of α1​, α2​, … αN​ into the linear algebraic equation.

    If it is a solution of each and every linear algebraic equation
    in a system, then it is said to be a solution of that system.

    If a system of linear algebraic equations has no solution, it is said to be inconsistent. If a system has either a unique solution or infinitely many solutions, it is said to be consistent.

    Legitimate Row Operations

    To solve a system of linear algebraic equations, express it
    as an upper triangular matrix, which is in the form shown
    on the right. This is achieved through row operations.

    ​1000​4100​5620​6803​​

    There are two types of legitimate row operations:

    • Interchanging of rows, Ri​ ↔ Rj​
    • Using row j to change row i to become Ri​ → αRi​+βRj​

    Homogeneous System

    A homogeneous system of linear algebraic equations is in the form:

    a11​x1​+a12​x2​+a13​x3​+...+a1N​xN​=0a21​x1​+a22​x2​+a23​x3​+...+a2N​xN​=0⋮aN1​x1​+aN2​x2​+aN3​x3​+...+aNN​xN​=0

    where x=0 is always a solution of the system, thus it is always consistent

    The homogeneous system AX=0 has either only one (unique) solution
    given by X=0 or infinitely many solutions, where one of which is X=0.

    #Vector Space

    A N-th dimensional vector is a well-ordered set
    of N real numbers in the form shown on the right.

    The set of all N-th dimensional vectors forms a vector
    space denoted by RN. For example, R3 is the set of all
    three-dimensional vectors.

    ​x1​x2​⋮xN​​​

    Linearly Dependent Vectors

    We say that u is a linear combination of v1​, v2​, …, vk−1​, and vk​ in the form:

    u=a1​v1​+a2​v2​+...+ak−1​vk−1​+ak​vk​

    where a1​, a2​, …, ak−1​, and ak​ are real numbers
    and     v1​, v2​, …, vk−1​, and vk​ are vectors in RN

    If any of the vectors can be expressed as a combination
    of the other vectors, the vectors are linearly dependent.

    Linearly Independent Vectors

    We say that w1​, w2​, …, wp−1​, and wp​ are linearly independent vectors if we cannot
    find any one of these vectors to be a linear combination of the other vectors.

    To determine whether vectors are linearly independent, form a homogeneous system:

    c1​w1​+c2​w2​+...+cp−1​wp−1​+cp​wp​=0

    If c1​=c2​=...=cp​=0 is the only solution, the vectors are linearly independent.

    If we can find c1​=0, then the relation becomes w1​=−c1​c2​​w2​−c1​c3​​w3​−...−c1​cp​​wp​.
    That is,     w1​ can be expressed as a linear combination of w2​, w3​, …, wp−1​ and wp​.

    #Inverse of a Square Matrix

    B is said to be an inverse of A if the relation AB=BA=I is true.

    If a square matrix A has an inverse, it can only have one inverse matrix.
    If     A has an inverse, A is invertible, with the inverse of A denoted by A−1.

    To determine whether A is invertible:

    • Form the tableau A∣I
    • Perform legitimate row operations
    • Reduce A∣I to the form I∣V (if possible)

    If A can be reduced to I via row operations, then V is the inverse of A.
    If     A cannot be reduced to I, then A is not invertible.

    Consider the system AX=B. If A−1 exits, then we can write:

    A−1AX=A−1BIX=A−1BX=A−1B

    If the inverse of A is known, it can be used to find the unique solution of the system.

    A and B are N×N matrices which are invertible. Show that (AB)−1=B−1A−1.

    (AB)(B−1A−1)=A(BB−1)A−1=AIA−1=AA−1=I

    Multiplying the original matrix with its inverse should return I.

    #Determinant of a Square Matrix

    Determinant of a Square Matrix

    Elements aij​ of a matrix A can be used to compute its determinant, det(A) or ∣A∣.

    Calculate det(A) using the I-th row, with elements, aI1​, aI2​, …, aIj​ and aIN​.

    det(A)=j=1∑N​  (−1)I+j ⋅ aIj​ ⋅ det(AIj​)

    where det(AIj​) is a matrix obtained by removing the I-th row and j-th column

    Calculate det(A) using the J-th column, with elements a1J​, a2J​, …, aiJ​ and aNJ​.

    det(A)=i=1∑N​  (−1)i+J ⋅ aiJ​ ⋅ det(AiJ​)

    where det(AiJ​) is a matrix obtained by removing the i-th row and J-th column

    Determinant of a Triangular Matrix

    The determinant of a triangular matrix is the product of all the diagonal elements.

    det​u11​0000​u12​u22​000​u13​u23​u33​00​u14​u24​u34​u44​0​u15​u25​u35​u45​u55​​​

    =(−1)1+1⋅u11​⋅det​u22​000​u23​u33​00​u24​u34​u44​0​u25​u35​u45​u55​​​

    =u11​⋅(−1)1+1⋅u22​⋅det​u33​00​u34​u44​0​u35​u45​u55​​​

    =u11​⋅u22​⋅u33​⋅u44​⋅u55​

    The determinant of any matrix can be found by reducing it to a triangular matrix.

    When we interchange rows Ri​ ↔ RJ​: it becomes −1⋅det(A)=det(U)
    When we multiply Ri​ → αRi​+βRj​: it becomes α⋅det(A)=det(U)

    Note that when row operations are performed, det(A)=det(U). We have to
    trace back the row operations performed and apply the appropriate relation.

    Determinant det(A)=0:

    • Matrix A is invertible
    • AX=B has a unique solution
    • Diagonal elements of U are non-zero

    Determinant det(A)=0:

    • Matrix A does not have an inverse
    • AX=B has either no solutions
      or infinitely many solutions

    For a homogeneous system where AX=0:

    • If det(A)=0, then AX=0 has a unique solution given by X=0
    • If det(A)=0, then AX=0 has infinitely many solutions

    Computing the determinant of a homogeneous system allows us to determine if the
    vectors that make up the system are linearly dependent or independent based on
    the value of     det(A).

    #Matrix Eigenvalue Problem

    Consider multiplying non-zero vectors by a given square matrix,

    [64​37​][51​]=[3327​] and [64​37​][34​]=[3040​]=10[34​]

    In the second example, the multiplication produces a new vector which has the
    same direction as the original vector, only differing by an eigenvalue λ=10.

    The problem of systematically finding λ and non-zero vectors for a given square
    matrix is known as the matrix eigenvalue problem, which can be expressed as,

    AX=λX=λIX

    AX−λIX=0

    (A−λI)X=0

    The equation is in the form of a homogeneous
    system of algebraic equations. Thus, to obtain
    solutions that is not     X=0, the determinant
    must be     det(A−λI)=0.

    If matrix A is a N×N matrix, it can have up to N distinct eigenvalues.
    Solving the determinant, in the form of a polynomial, gives the values of λ.
    Substituting λ back into the homogeneous system gives the eigenvectors.

    #Diagonalization of a Square Matrix

    Given an N×N matrix A, can we find an invertible N×N matrix P and an N×N diagonal matrix D such that,

    A=PDP−1

    P−1AP=D

    D=​10000​02000​00300​00040​00005​​

    Matrix A can be diagonalized if and only if it has N linearly dependent eigenvectors.

    Suppose A has linearly dependent eigenvectors X1​, X2​, …, XN−1​, and XN​.

    P=[X1​​X2​​...​XN−1​​XN​​]

    where the matrix contains the eigenvectors

    D=​λ1​0000​0λ2​000​00⋱00​000λN−1​0​0000λN​​​​

    where the diagonal elements are the eigenvalues

    Matrix of a Higher Power

    If matrix A can be diagonalized, we can compute AM for higher power M.

    A5=PDP−1⋅PDP−1⋅PDP−1⋅PDP−1⋅PDP−1

    A5=PDIDIDIDIDP−1

    A5=PD5P−1

    In general, AM=PDMP−1.

    Diagonalization of a Symmetric Matrix

    If A is an N×N symmetric matrix whose elements are real numbers, then it
    has real eigenvalues. If the symmetric matrix has N distinct eigenvalues with
    unit norm eigenvectors, then we can form a matrix P such that P−1=PT.

    The norm of a vector X is denoted by ∣∣X∣∣=x1​2+x2​2+...+xN​2​.

    The diagonalization equation becomes A=PDPT.

    #Parametric Equations

    #Equation of a Plane

    Let P=(x0​, y0​, z0​) be a fixed point on a plane.

    Let Q=(x, y, z) be a general point on a plane.

    The normal vector of the plane is u=(a, b, c).

    The vector PQ is perpendicular to u such that PQ⋅u=0.

    The equation of the plane is ax+by+cz=d, where d is a constant.

    Consider the plane x+2y+3z=6.

    Let z=t and y=s, where t and s are arbitrary numbers.

    The parametric equations of the plane are then,
    x=6−2s−3ty=sz=t

    In general, the parametric equations are,

    x=α1​s+β1​u+γ1​y=α2​s+β2​u+γ2​z=α3​s+β3​u+γ3​

    where x, y, and z are expressed as linear functions

    #Equation of a Surface

    Points on a surface in 3D space can be represented by F(x, y, z)=d.

    The surface may be described using parametric equations where
    the coordinates of its points are given by functions of s and u.

    x=f(s, u)y=g(s, u)z=h(s, u)

    If the above functions are linear, they describe a plane.

    Express the surface (x−1)2+(y−2)2+(z−3)2=16 in parametric form.

    Let ρ=z−3.

    (x−1)2+(y−2)2=16−ρ2

    Since the LHS is always positive, −4≤ρ≤4.

    Using the trigonometric identity,

    (sinθ)2+(cosθ)2=1

    (asinθ)2+(acosθ)2=a2

    Let a=16−ρ2​.

    x−1=16−ρ2​sinθ

    y−2=16−ρ2​cosθ

    The parametric equations are then,

    x=1+16−ρ2​sinθy=1+16−ρ2​cosθz=ρ+3

    #Equation of a Line

    Let P=(x0​, y0​, z0​) and R=(x1​, y1​, z1​) be two points on a line.

    Let Q=(x, y, z) be a general point on the same line.

    PR=(x1​−x0​, y1​−y0​,z1​−z0​)

    PQ=(x−x0​, y−y0​, z−z0​)

    Since the vectors are parallel, PQ=tPR.

    (x−x0​, y−y0​, z−z0​)=t(x1​−x0​, y1​−y0​,z1​−z0​)

    The parametric equations for the line are then,

    x=x0​+t(x1​−x0​)y=y0​+t(y1​−y0​)z=z0​+t(z1​−z0​)

    where (x, y, z)is a general point on the line,
    (x0​, y0​, z0​) is a given point on the line, and
    (x1​−x0​, y1​−y0​, z1​−z0​) is a vector parallel to the line

    #Equation of a Curve

    All points on a curve in 3D space can expressed in parametric form.

    x=F(s)y=G(s)z=H(s)

    If the above functions are linear, they describe a line.

    #Vector Differential

    A vector function F of one variable u is in the form:

    F(u)=p(u)i+q(u)j+r(u)k

    F(u)=[p(u), q(u), r(u)]

    Differentiation of a Vector

    Let a be a scalar function of x.

    Let G=p(x)i+q(x)j+r(x)k.

    Determine the derivative of dxd​ aG.

    dxd​ aG=[dxd​ ap, dxd​ aq, dxd​ ar]

    dxd​ aG=[adxdp​+pdxda​, adxdq​+qdxda​, adxdr​+rdxda​]

    dxd​ aG=a[dxdp​, dxdq​, dxdr​]+dxda​[p, q, r]

    dxd​ aG=adxdG​+Gdxda​

    The derivative of a scalar multiplied with a vector gives the product rule.

    Differentiation of Dot Product of Vectors

    Let F(t)=p(t)i+q(t)j+r(t)k.

    Let G(t)=u(t)i+v(t)j+w(t)k.

    Determine the derivative of dtd​ F⋅G.

    dtd​ F⋅G=dtd​ pu+qv+rw

    dtd​ F⋅G=dtd​ pu+dtd​ qv+dtd​ rw

    dtd​ F⋅G=pdtdu​+udtdp​+qdtdv​+vdtdq​+rdtdw​+wdtdr​

    dtd​ F⋅G=[p, q, r]⋅[dtdu​, dtdv​, dtdw​]+[u, v, w]⋅[dtdp​, dtdq​, dtdr​]

    dtd​ F⋅G=F⋅dtdG​+G⋅dtdF​

    The derivative of a vector dot product gives the product rule.

    Directional Derivative

    Unit vector u=∣v∣v​

    dtd​ f(x, y, z)=∇f⋅u

    dtd​ f(x, y, z)=∂x∂f​⋅u1​+∂y∂f​⋅u2​+∂z∂f​⋅u3​

    At a point (a, b, c), directional derivative is the rate of change of f in the direction u.

    Vector Functions

    The ∇ operator is also called the grad() function.

    ∇f(x, y, z)=[∂x∂f​, ∂y∂f​, ∂z∂f​]

    The ∇⋅ operator is also called the div() function.

    ∇⋅F=[∂x∂​, ∂y∂​, ∂z∂​]⋅[p, q, r]=∂x∂q​+∂y∂r​+∂z∂s​

    The ∇× operator is also called the curl() function.

    ∇×F=[∂x∂​, ∂y∂​, ∂z∂​]×[p, q, r]

    ∇×F=[∂y∂r​−∂z∂q​, ∂z∂p​−∂x∂r​, ∂x∂q​−∂y∂p​]

    Cross product determined using the shortcut method for determinant of a 3×3 matrix.

    The ∇⋅∇ operator (scalar) is also known as the Laplacian operator.

    ∇⋅∇=∇2=∂x2∂2​+∂y2∂2​+∂z2∂2​

    #Vector Integral

    Double Integral (Polar Coordinates)

    ∬R​dA=∬R​rdrdθ

    Express x and y as x=rcosθ and y=rsinθ.

    Line Integral

    Consider the integral of a curve C in a 2D space.

    ∫C​ f(x,y,z) ds can be computed by expressing f in parametric equations.

    ds=(dtdx​)2+(dtdy​)2+(dtdz​)2​ dt

    Green’s Theorem

    Consider the integral of a closed curve C in a 2D space.

    The curve C is assigned an anticlockwise direction (positive).

    ∮C​ [f(x,y), g(x,y)]⋅[dx, dy]

    =∮C​ f(x,y)dx+g(x,y)dy

    =∬R​ ∂x∂g​−∂y∂f​ dA

    The closed integral can be evaluated as a double integral.

    Consider a 2D force field F=f(x,y)i+g(x,y)j.

    The 2D force field is said to be conservative if ∂x∂g​=∂y∂f​.

    If it is conservative, then ∇ϕ=F where ϕ(x,y) is the potential function of F.

    Surface Integral

    If the equation of surface S can be written in the form z=f(x,y),

    dσ=1+(∂x∂f​)2+(∂y∂f​)2​ dA

    The surface is projected onto the xy-plane where z=0.

    If the equation of surface S can be written in the form x=f(y,z),

    dσ=1+(∂y∂f​)2+(∂z∂f​)2​ dA

    The surface is projected onto the yz-plane where x=0.

    Flux across a Surface

    Let u(x,y,z) be a vector field, S be a surface, and n be the unit normal vector.

    Flux across the surface in the direction of n is ∬S​ u(x,y,z)⋅n dσ.

    Flux across a Closed Surface

    Consider the flux of the vector field u(x,y,z) across a closed surface S
    in the direction of n, where n is the outward unit normal vector to S.

    ∬S​ u⋅n dσ=∭T​ ∇⋅u dV

    Total flux can be determined by integrating each surface individually or
    by using the Gauss-Ostrogradski theorem (right-hand side of equation).

    Stoke’s Theorem

    Consider a surface S. The edge of S is a simple closed curve C.

    Work done by F over the closed curve C is a closed integral.

    ∮C​ F⋅dr=∬S​ (∇×F)⋅n dσ

    Since C is assigned the anticlockwise direction as positive, the direction of n, the
    unit normal vector of the surface S, is determined using the right-hand screw rule.

    The normal vector of the surface can be determined using ∇S.

    If a force field F(x,y,z) is such that ∇×F=0, the force field is conservative.

    If the force field is convservative, then ∇ϕ=F.
