    Digital Signal Processing

    #Number Systems

    #Binary Numbers

    Binary (base-2) system:

    • Simplicity in representation and processing
    • Easier error detection and correction
    • Directly related to on-off states

    #Binary Coded Decimals

    Binary coded decimals (BCD):

    • 4-bit nibble used to represent each digit of a decimal number
    • Ease of conversion between decimal and binary
    • Human-readable form

    #One’s and Two’s Complement

    One’s complement:

    • Each bit of the original binary number is inverted
    • For example, for binary number 011, its one’s complement is 100
    • Commonly used in error detection during data transmission and bitwise NOT

    Two’s complement:

    • Inverting all the bits of the original binary number and adding 1 to the result
    • For example, for binary number 011, its two’s complement is 101
    • Widely used to represent negative integers in computers

    #Octal Numbers

    Octal (base-8) system:

    • Represented by 0, 1, 2, 3, 4, 5, 6, 7 in the octal system
    • Each octal digit is represented by 3 bits in the binary system

    #Hexadecimal Numbers

    Hexadecimal (base-16) system:

    • 0-9 for values zero to nine
    • A-F for values ten to fifteen
    • Hexadecimal number 2F = decimal number 47
    • Each hexadecimal digit is represented by 4 bits in the binary system

    #Logic Circuits

    Logic circuits are electronic circuits that perform operations based on Boolean algebra.

    Signal flow through a circuit:

    • Input signals are binary signals from sensors, switches, etc.
    • Signals move through the circuit and encounter logic gates
    • Each gate performs a specific logic operation on the input signal
    • After passing through a gate, signal may encounter another gate
    • Propagation delay — takes time for a signal to travel from input to output of a gate
    • Signals exit the logic circuit after being manipulated by the various components
    • Output signals are used to perform specific tasks (triggering an action)

    Fan-in:

    • Number of input signals that a digital logic gate can accept
    • Gates with larger fan-in tend to operate more slowly due to complex input circuitry

    Fan-out:

    • Maximum number of inputs a single logic gate’s output can safely drive
    • One output is often connected to multiple inputs of other logic gates

    #Logic Gates

    Buffer gate:

    • Produce an output that is the same as its input
    • Serves as a conduit to transmit a signal from
      one circuit to another without altering data
    • Used for signal integrity maintenance

    NOT gate:

    • Inverts its input

    #Boolean Algebra

    Purpose of Boolean algebra:

    • Used for analyzing and simplifying digital circuits
    • Simplify complex logic expressions to create more efficient circuit designs
    • Crucial in aircraft systems where space, weight, and power are limited resources

    FunctionLogic Expressions

    ORY=A+B

    Simplification techniques:

    • A+AB+BC=A+AB

    #Combinational Logic

    Combinational logic circuits produce an output based on the current inputs.

    • Gates can be combined to form complex logic functions
    • Advantages — speed, reliability, and ease of implementation
    • Limitations — lack of memory, complexity increases with number of inputs/outputs

    #Flip Flops

    #Bistables

    An electronic circuit that has two stable states and can be used to store binary data.

    • Stable states are represented as 0 and 1, or low and high
    • Output will remain indefinitely at a state until reset

    “Set” state:

    • If input R is at 0 and input S is at 1
    • Output Q​ of NAND gate Y must be 1 since at least one of its inputs is 0
    • Output Q​ is fed back to NAND gate X such that both inputs to X are 1
    • Output Q of NAND gate X is 0
    • If input R changes state to 1
    • Output Q​ of NAND gate Y remains at 1 since B remains at 0
    • There is no change of state (circuit is said to be “set” with Q​=1 and Q=0)

    “Reset” state:

    • Outputs Q​ is 0 and Q is 1, and is given by R=1 and S=0
    • Output of NAND gate X must be 1 since S=0 (at least one input is 0)
    • Output Q is fed back to NAND gate Y such that both inputs to Y are 1
    • Output Q​ of NAND gate Y is therefore 0
    • If input S changes state to 1
    • Output Q of NAND gate X remains at 0 since A remains at 0
    • There is no change of state (circuit “Reset” state has been latched)

    Triggering mechanisms:

    • Edge-triggered — changes state only during transition of clock signal (rising/falling)
    • Level-triggered — changes state as long as input condition is met (high/low level)
    • Holding state — absence of triggering signal, “hold” its last state indefinitely

    #Monostables

    Monostable:

    • One stable state and one unstable state
    • Used for generating a single output pulse
      in response to an external trigger pulse

    Basic operation:

    • Circuit is triggered by an external trigger pulse
    • Circuit then transitions from stable to unstable state
    • Monostable then generates a single output pulse
    • Duration of output pulse is given by t=1.1RC
    • After the output pulse, circuit returns to stable state

    #S-R (Set-Reset) Flip Flop

    Consider the starting state:

    • Inputs set and reset are both 0
    • Output Q=1 and output Q​=0

    When reset is changed to 1:

    • Input to the top NOR gate will be 1 and 0
    • Output Q=0
    • Input to the bottom NOR gate will be 0 and 0
    • Output Q​=1

    When reset is changed back to 0:

    • Input to the top NOR gate will be 0 and 1
    • Output Q=0
    • Input to the bottom NOR gate remains at 0 and 0
    • No change in output Qˉ​=1

    #D (Data/Delay) Flip Flop

    Data flip flop is a type of digital storage element
    that samples and holds the value of an incoming signal at the edge of a clock pulse.

    • 2 inputs — data input and clock input
    • 2 outputs — Q and complimentary Q​
    • Output state only changes with the clock
    • Value of data input is transferred to output Q
      on the rising or falling edge of the clock pulse

    Clock signals ensure that changes in state
    are synchronized across multiple flip flops
    or other digital circuit elements.

    #J-K (Jack Kilby) Flip Flop

    Flip flop:

    • More versatile flip flop
    • 1 clock input (for clock pulse)
    • 2 clocked inputs — J and K
    • 2 direct inputs — preset and clear
    • 2 outputs — Q and complimentary Q​

    #Analog-to-Digital Converter (ADC)

    Quantization:

    • Process of mapping a continuous range of values to a finite range of discrete values
    • Final step in ADC where sampled analog values are mapped to discrete digital levels
    • Quantization interval — range of input values mapped to the same digital output level
    • Quantization levels — number of discrete levels which analog signal can be mapped
    • Quantization step — difference between adjacent quantization levels
    • Quantization error — difference between analog and digital value
    • Quantization error can lead to information loss and signal noise

    #Flash Conversion ADC

    Flash ADC (parallel ADC):

    • Converts an entire analog signal to digital almost instantaneously
    • Uses an array of comparators (set at different reference voltages)
    • All the comparators evaluate the analog signal simultaneously
    • Priority encoder translates comparator outputs to binary code

    Advantages:

    • Extremely fast conversion times
    • Suitable for real-time data processing

    Disadvantages:

    • High power consumption (parallel)
    • High cost due to more components

    #Ramp-Type ADC

    Ramp-type ADC:

    • Uses a counter to generate a digital output corresponding to analog input
    • Counter outputs a digital signal which is then converted to analog
    • This analog signal is compared against the input analog signal
    • Counter stops only when comparator indicates a match

    Advantages:

    • Relatively easy to implement
    • Low cost

    Disadvantages:

    • Slower than other methods
    • Limited by max. count of counter

    #Up-Down Counters

    Up-down counter:

    • Digital counter that counts up/down through a sequence of states
    • Comparator compares input analog signal to generated analog signal
    • If generated analog signal is lower than input analog signal, then count up
    • If generated analog signal is higher than input analog signal, then count down

    #Successive Approximation ADC

    Successive approximation ADC:

    • Approximates the analog signal in successive steps until closest digital value is found
    • Comparator compares current approximation to the actual analog signal
    • Register stores the current approximation

    Algorithm:

    • Initialization — Start with the most significant bit (MSB) set to 1, other set to 0
    • Comparison — if current approx. lower than actual, keep MSB at 1 and vice versa
    • Iteration — next clock cycle, MSB set at 1 with the next most significant bit set at 1
    • Comparator compares again

    Advantages:

    • High accuracy
    • Moderate speed

    Disadvantages:

    • Complexity increases with resolution
    • Higher power consumption

    #Digital-to-Analog Converter (DAC)

    Components of a converter:

    • Input register — holds the value to be converted
    • Reference voltage — provides the scale for conversion
    • Output amplifier — amplifies the converted analog signal

    #Binary-Weighted DAC

    Binary-weighted DAC:

    • DAC receives a digital signal (series of 1 and 0)
    • Each bit assigned a resistor based on its significance
    • MSB is given the least resistor value (most influential)
    • Bits that are 0 contribute no current

    Output voltage:

    • Determine the current for each resistor using Ohm’s law V=IR
    • Sum the currents through the resistors to obtain the total current
    • Multiply total current with the resistor in the feedback loop

    #Resolution and Accuracy

    Resolution and accuracy determine how closely
    a digital output can represent an analog input.

    Resolution:

    • Smallest change in analog input that will result in a change in digital output
    • Bit depth — expressed in terms of bits (8-bit, 16-bit, etc.)
    • Resolution — number of levels, full scale range

    Accuracy:

    • Degree to which the digital output of the ADC matches the actual analog input
    • Error types — quantization error, non-linearity, and noise
    • Measurement — expressed as a % or in terms of LSBs
