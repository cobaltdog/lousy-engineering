    #3-Node Bar Element

    Element characteristics:

    • Two end nodes and a central node, quadratic shape functions
    • Displacement field is a smooth quadratic curve across element

    Coordinate transformation equation,

    ζ=x2​−x1​2(x−x3​)​

    Making x the subject of the equation,

    x=(−2ζ​)x1​+(2ζ​)x2​+x3​

    dx=21​(x2​−x1​) dζ

    dx=2le​​ dζ

    Displacement field within the element is,

    u=Nq=N1​q1​+N2​q2​+N3​q3​

    Quadratic shape functions are,

    N1​=−21​ζ(1−ζ)

    N2​=21​ζ(1+ζ)

    N3​=(1+ζ)(1−ζ)

    Strain matrix of the element is,

    B=dxdN​=dζdN​⋅dxdζ​

    💡

    B=le​2​[−21−2ζ​​21+2ζ​​−2ζ​]

    Element stiffness matrix,

    ke=∫e​ BTDB dVe​

    ke=(Ae​Ee​)∫−11​ BTB dx

    ke=(Ae​Ee​)∫−11​ BTB⋅2le​​ dζ

    💡
    ke=3le​Ae​Ee​​​71−8​17−8​−8−816​​

    Nodal force vector due to body force f and traction load T,

    fe=∫e​ (NTf) dVe​+∫e​ (NTT) dSe​

    fe=∫e​​N1​N2​N3​​​fAe​ dx+∫e​​N1​N2​N3​​​T dx

    💡
    fe=Ae​le​f​1/61/62/3​​+le​T​1/61/62/3​​

    Assuming both f and T are constants.

    Nodal force vector due to temperature,

    fθ​e=∫e​ BTDε0​ dVe​

    fθ​e=∫e​ BTE(αΔT)Ae​ dx

    fθ​e=Ae​EαΔT∫e​ BT⋅2le​​ dζ

    💡
    fθ​e=Ae​EαΔT​−110​​

    Note that there is no contribution to the central node.
    Thus, it is similar to the case for a 2-node bar element.

    #Plane Truss Element

    Element characteristics:

    • 4 DOF per element (2 DOF per node)
    • An inclined bar element designed to resist direct tension and compression

    Consider a bar element inclined at an angle θ to the global x-axis.

    Note that θ is measured anticlockwise from the global x-axis.

    Displacements of the element,

    q1′​=q1​cosθ+q2​sinθ

    q2′​=q1​sinθ+q2​cosθ

    In matrix form, the displacements are,

    {q1′​q2′​​}=[cosθ0​sinθ0​0sinθ​0cosθ​]⎩⎨⎧​q1​q2​q3​q4​​⎭⎬⎫​

    q′=Lq

    where q′ are the local displacements (when viewed as a bar element),
    and     q are the global displacements (when viewed as a truss element)

    Let l=cosθ and m=sinθ.

    L=[l0​m0​0m​0l​]

    By using the transformation matrix L, equations for a 2-node bar
    element can be modified to give the equations for a truss element.

    Element stiffness matrix for a truss element in the global coordinate system,

    💡

    ke=LTk′L=le​Ae​Ee​​​l2lm−l2−lm​lmm2−lm−m2​−l2−lml2lm​−lm−m2lmm2​​

    where k′ is the element stiffness matrix for a 2-node bar element

    Strain matrix for a truss element in the global coordinate system,

    σ=Eε=EB′q′=EB′Lq=EBq

    B=B′L=le​1​[−1​1​][l0​m0​0m​0l​]

    💡

    B=le​1​[−l​−m​l​m​]

    where B′ is the strain matrix for a 2-node bar element

    Nodal force vector due to body force f and surface traction T,

    fe=LTf′

    fe=LT{∫e​ (NTf) dVe​+∫e​ (NTT) dSe​}

    💡

    fe=2Ae​le​f​​lmlm​​+2le​T​​lmlm​​

    where f′ is the nodal force vector for a 2-node bar element

    Nodal force vector due to temperature,

    fθ​e=∫e​ BTDε0​ dVe​

    fθ​e=∫e​ (BTEε0​)Ae​ dx

    💡

    fθ​e=Ae​Ee​αΔT​−l−mlm​​

    #Beam Element

    Element characteristics:

    • 4 DOF per element (2 DOF per node)
    • Transverse and angular displacements
    • Axial displacements are ignored in element

    StressStrainMoment-CurvatureStrain Energy
    σ=−IMy​ε=Eσ​M=EIdx2d2w​U=21​∫0L​ EI(dx2d2w​)2 dx

    where w is the vertical displacement (deflection) of the beam,
    such that     w=c1​+c2​x+c3​x2+c4​x3 (cubic equation)

    Nodal displacements at node 1,

    q1​=w∣node 1​

    q2​=dxdw​​node 1​

    Nodal displacements at node 2,

    q3​=w∣node 2​

    q4​=dxdw​​node 2​

    Displacement field,

    w(ζ)=H1​w1​+H2​(dqdζ​)1​+H3​w3​+H4​(dqdζ​)2​

    💡

    w(ζ)=H1​q1​+2le​​H2​q2​+H3​q3​+2le​​H4​q4​

    Hermite (cubic) shape functions,

    H1​=41​(1−ζ)2(2+ζ)

    H2​=41​(1−ζ)2(1+ζ)

    H3​=41​(1+ζ)2(2−ζ)

    H4​=41​(1+ζ)2(ζ−1)

    where leftmost point ζ=−1, center point ζ=0, rightmost point ζ=1

    Shape functions for w=Nq,

    N1​=41​(2−3ζ+ζ3)

    N2​=8le​​(1−ζ−ζ2+ζ3)

    N3​=41​(2+3ζ−ζ3)

    N4​=8le​​(−1+ζ+ζ2−ζ3)

    Strain energy in a single element,

    Ue​=21​qTkeq

    Ue​=21​∫0L​ EI(dx2d2w​)2 dx

    Ue​=21​∫−11​ EI{dx2d2​[Nq]}T{dx2d2​[Nq]}2le​​ dζ

    Ue​=21​∫−11​ le​38EI​[q]T[dζ2d2N​]T[dζ2d2N​][q] dζ

    Ue​=21​[q]T{le​38EI​∫−11​ [dζ2d2N​]T[dζ2d2N​] dζ}[q]

    Beam element stiffness matrix,

    ke=le​38EI​∫−11​ [dζ2d2N​]T[dζ2d2N​] dζ

    kij​e=le​38EI​∫−11​ dζ2d2Ni​​⋅dζ2d2Nj​​ dζ

    💡

    ke=le​3EI​​126l−126l​6l4l2−6l2l2​−12−6l12−6l​6l2l2−6l4l2​​

    Matrix elements are obtained by differentiating the shape functions.

    Nodal load vector for a uniformly distributed load P,

    fe=∫e​ (NTT) ds

    fe=2le​​∫e​ NTT(ζ) dζ

    fe=2Ple​​∫−11​ [N1​​N2​​N3​​N4​​]T dζ

    💡

    fe=[2Ple​​​12Ple​2​​2Ple​​​−12Ple​2​​]T

    Note that P is positive for an upward acting distributed load and vice versa.
