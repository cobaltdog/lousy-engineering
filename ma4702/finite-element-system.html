    Finite Element System

    #Global Stiffness Matrix [K]

    Consider an assembly consisting of a bar and a truss element.
    The bar element has 2 DOF while the truss element has 4 DOF.

    Local stiffness matrix of bar element,

    {f1​(1)f2​(1)​}=[k11​(1)k21​(1)​k12​(1)k22​(1)​]{q1​(1)q2​(1)​}

    Element stiffness matrix corresponds to Q1​ and Q2​.

    Local stiffness matrix of truss element,

    ⎩⎨⎧​f1​(2)f2​(2)f3​(2)f4​(2)​⎭⎬⎫​=​k11​(2)k21​(2)k31​(2)k41​(2)​k12​(2)k22​(2)k32​(2)k42​(2)​k13​(2)k23​(2)k33​(2)k43​(2)​k14​(2)k24​(2)k34​(2)k44​(2)​​⎩⎨⎧​q1​(2)q2​(2)q3​(2)q4​(2)​⎭⎬⎫​

    Element stiffness matrix corresponds to Q2​, Q3​, Q4​ and Q5​.

    Combining above matrices, we get the combined global stiffness matrix.

    #Global Force Vector {F}

    The system of loads on the actual structure is replaced
    by an equivalent system of forces at the element nodes.

    • Concentrated loads — nodes are created at the load points
    • Distributed loads — replaced by equivalent nodal forces

    Nodal force {F} is arranged in the same way as global DOF vector {Q}.

    #Boundary Conditions

    A structure must be fixed to prevent rigid body displacement.

    Types of boundary conditions:

    • Zero displacements at non-yielding supports
    • Non-zero displacements
    • Multi-point constraints

    #Elimination Approach

    Using 1D bar elements, formulate the FEM problem such that the nodal displacements
    at points 2, 3, and 4, and the reaction forces at the fixed edges can be determined.

    Local stiffness matrix of each element,

    k(1)=L1​A1​E1​​[1−1​−11​]=[k11​(1)k21​(1)​k12​(1)k22​(1)​]

    k(2)=L2​A2​E2​​[1−1​−11​]=[k11​(2)k21​(2)​k12​(2)k22​(2)​]

    k(3)=L3​A3​E3​​[1−1​−11​]=[k11​(3)k21​(3)​k12​(3)k22​(3)​]

    Assemble the global stiffness matrix.

    Equivalent nodal force due to surface traction in element 1,

    f(1)=2l1​T​[11​]=T[L1​/2L1​/2​]

    Writing the finite element system,

    F=KQ

    ⎩⎨⎧​F1​F2​F3​F4​​⎭⎬⎫​=​K11​K21​K31​K41​​K12​K22​K32​K42​​K13​K23​K33​K43​​K14​K24​K34​K44​​​⎩⎨⎧​Q1​Q2​Q3​Q4​​⎭⎬⎫​

    ⎩⎨⎧​TL1​/2+R1​TL1​/2PR4​​⎭⎬⎫​=​K11​K21​K31​K41​​K12​K22​K32​K42​​K13​K23​K33​K43​​K14​K24​K34​K44​​​⎩⎨⎧​Q1​Q2​Q3​Q4​​⎭⎬⎫​

    Since Q1​=0 and Q4​=0, the system reduces to,

    {TL1​/2P​}=[K22​K32​​K23​K33​​]{Q2​Q3​​}

    Eliminate the 1st and 4th rows, and the 1st and 4th columns.

    After reduction, we can solve for Q2​ and Q3​ using the above matrix.
    Reaction forces R1​ and R4​ can be obtained using the original matrix.

    #Exploiting Symmetry

    Solving FE when there is symmetry:

    • Truss along line of symmetry — area needs to be halved
    • Force along line of symmetry — force needs to be halved
    • Horizontal truss is cut by symmetry line — treat as two separate elements

    #Numerical Integration

    Gauss quadrature method is defined as,

    I=∫−11​ f(ζ) dζ

    I≈i=1∑n​ wi​⋅f(ζi​)

    I=w1​f(ζ1​)+w2​+f(ζ2​)+⋯+wn​f(ζn​)

    where w is the weight, and f is the functional value

    It can be shown that an n-point Gauss quadrature yields
    an exact answer for a polynomial of order 2n−1 or less.

    Given an integral:

    • Choose the number of points n to evaluate
    • Obtain the corresponding location ζi​ and weight wi​
    • Substitute x=ζi​ into the function to obtain value of the function at that location
    • Substitute the respective weights wi​ and function values f(ζi​) to obtain final result

    Gauss quadrature can be applied to 2D integrals.

    I=∫−11​∫−11​ f(ζ,η) dζdη

    I≈∫−11​[i=1∑n​ wi​⋅f(ζi​,η)] dη

    I≈j=1∑n​ wj​[n=1∑n​ wi​⋅f(ζi​,ηj​)]

    I=i=1∑n​j=1∑n​ wi​wj​⋅f(ζi​,ηj​)
