    Linear Systems Theory

    #Linearization of Non-Linear Equations

    For a non-linear system x˙=f(x,u), derive an approximate linear system x˙=Ax+Bu.

    where x represent state vectors (aircraft linear and angular velocities),
    and     u represent control vectors (flight control surfaces deflection)

    • Operating point — any point within the operating characteristics of given system
    • Equilibrium point — a point xe​ (under a given control input u=u0​) where x˙=0

      Equilibrium point corresponds to the point whereby the system is static (zero velocity).

    #Single-Variable System

    Linearize the equation x˙=f(x) around the operating point (x0​,x˙0​).

    Consider small variations in the state variable around the operating point.

    x=x0​+Δx

    x˙=x˙0​+Δx˙

    Using Taylor series expansion,

    x˙=f(x)=f(x0​)+f′(x0​)1!Δx​+f′′(x0​)2!Δx​+f′′′(x0​)3!Δx​+…

    x˙=f(x)≈f(x0​)+f′(x0​)Δx (ignoring the higher-order terms)

    Comparing the expressions for x˙,

    x˙0​+Δx˙≈f(x0​)+f′(x0​)Δx

    💡

    Δx˙=f′(x0​)Δx=AΔx

    At the operating point (x0​,x˙0​), the non-linear equation is satisfied where x˙0​=f(x0​).
    Note that in practice, a non-linear equation is linearized around its equilibrium point     xe​.
    Thus, we must first find the equilibrium point by solving the equation     0=f(xe​,uo​).

    #Example: Single-Variable with No Control Input

    Linearize the equation y¨​+y˙​+cosy=0 around its equilibrium points.

    Equilibrium point where f(ye​)=0,

    y¨​e​+y˙​e​+cosye​=0

    cosye​=0

    ye​=2π​

    Taking small variations around the equilibrium point,

    y=ye​+Δy

    y˙​=y˙​e​+Δy˙​=Δy˙​

    y¨​=y¨​e​+Δy¨​=Δy¨​

    y¨​+y˙​+cosy=0

    Linearized equation about the equilibrium point,

    Δy¨​+Δy˙​−Δy=0

    #Example: Single-Variable with Control Input

    Linearize the following non-homogenous system around its equilibrium points.

    y˙​−u˙−uy−y=0 where y≡y(t) and u≡u(t)

    Rewriting the system,

    f(y,u)=y˙​−u˙=uy+y

    Let control input at the equilibrium point be u=ue​=0.

    Equilibrium point where f(ye​,ue​)=0,

    0=ue​ye​+ye​

    0=0⋅ye​+ye​

    ye​=0

    ∴   ye​=0,ue​=0 (Equilibrium point)

    Taking small variations around the equilibrium point,

    y=ye​+Δy

    y˙​=y˙​e​+Δy˙​=Δy˙​

    u=ue​+Δu

    u˙=u˙e​+Δu˙=Δu˙

    Linearizing the equation,

    y˙​−u˙−uy−y=0

    Δy˙​−Δu˙−(ue​+Δu)(ye​+Δy)−(ye​+Δy)=0

    Δy˙​−Δu˙−(ue​ye​+ue​Δy+ye​Δu+ΔuΔy)−(ye​+Δy)=0

    Δy˙​−Δu˙−(ue​ye​+ue​Δy+ye​Δu)−(ye​+Δy)=0

    Note that the term ΔuΔy is neglected.

    Linearized equation about the equilibrium point,

    Δy˙​−Δu˙−(0⋅0+0⋅Δy+0⋅Δu)−(0+Δy)=0

    Δy˙​−Δu˙−Δy=0

    #2nd-Order System

    Consider a spring-mass-damper system.

    Initial conditions are given as,

    x(0)=x0​

    x˙(0)=x˙0​

    Applying Newton’s 2nd law,

    F(t)−cx˙−kx=mx¨

    mx¨+cx˙+kx=F(t)

    Performing Laplace transform,

    m[s2⋅X(s)−s⋅x(0)−x˙(0)]+c[s⋅X(s)−x(0)]+k⋅X(s)=F(s)

    ms2⋅X(s)+cs⋅X(s)+k⋅X(s)=F(s)+(ms+c)⋅x(0)+m⋅x˙(0)

    (ms2+cs+k)⋅X(s)=F(s)+(ms+c)x0​+mx˙0​

    💡

    X(s)=ms2+cs+kF(s)​+ms2+cs+k(ms+c)x0​+mx˙0​​

    Transfer function of the system,

    T(s)=F(s)X(s)​=ms2+cs+k1​

    Let initial conditions x0​=0 and x˙0​=0.

    Total response of the system, in terms of the transfer function,

    💡

    X(s)=T(s)⋅F(s)+T(s)[(ms+c)x0​+mx˙0​]

    1st term represents the forced response.
    2nd term represents the free response.

    #System Stability

    Characteristic equation of the system is,

    CE=ms2+cs+k

    Roots of the characteristic equation are,

    s1,2​=2m−c±c2−4mk​​

    If c2−4mk>0, the system is overdamped (two distinct real poles).
    If c2−4mk<0, the system is underdamped (two complex poles).
    If c2−4mk=0, the system is critically damped (two repeated poles).

    If all the poles are to the left of the imaginary axis, the system is stable.
    If at least one pole is on the imaginary axis, the system is critically stable.
    If at least one pole is on the right of the imaginary axis, the system is unstable.

    Natural frequency of a system,

    💡

    ωn​=mk​​

    Critical damping constant of a system,

    💡

    ccr​=2km​=2mωn​=ωn​2k​

    Damping ratio of a system,

    💡

    ζ=ccr​c​=2km​c​=2mωn​c​=2k/ωn​c​

    Rewriting the transfer function expression,

    T(s)=ms2+cs+k1​

    T(s)=m(s2+mc​s+mk​)1​

    T(s)=m(s2+2ζωn​s+ωn​2)1​

    T(s)=mk(s2+2ζωn​s+ωn​2)k​

    T(s)=k1​⋅s2+2ζωn​s+ωn​2k/m​

    T(s)=k1​⋅s2+2ζωn​s+ωn​2ωn​2​

    Poles of the system are then,

    s1,2​=2−2ζωn​±4ζ2ωn​2−4ωn​2​​

    s1,2​=2−2ζωn​+2ωn​ζ2−1​​

    s1,2​=−ζωn​±ωn​ζ2−1​

    #Routh-Hurwitz Criterion

    Necessary conditions for a system to be stable:

    1. All the coefficients in the equation should have the same sign
    2. There should be no missing term in the polynomial

    These conditions are not sufficient to guarantee the stability of a system.

    • System is unstable if there is a sign change in the 1st column
    • Number of sign changes → number of poles with positive real parts

      Recall that if a pole lies on the right of the imaginary axis, it is unstable.

    #Special Cases of Criterion

    Special cases of the Routh table:

    • A zero only in the first column of a row
    • An entire row that consists of zeroes

    #Zero Only in the First Column

    If the first element of a row is zero:

    • Replace the zero with ε
    • ε is allowed to approach zero from either the positive or negative side
    • Determinants are expressed in terms of ε and signs of each element is determined

    If ε is chosen to be positive:

    • 1st sign change from the s3 row to the s2 row
    • 2nd sign change from the s2 row to the s1 row
    • System is unstable and has two roots in the right half-plane

    If ε is chosen to be negative:

    • 1st sign change from the s4 row to the s3 row
    • 2nd sign change from the s3 row to the s2 row
    • System is unstable and has two roots in the right half-plane

    #Entire Row is Zero

    Consider a closed-loop transfer function,

    T(s)=s5+7s4+6s3+42s2+8s+5610​

    Forming the Routh table for the denominator, the 3rd row becomes entirely zeroes.
    We form an auxiliary polynomial using elements in the row above it as coefficients.

    Thus, we form the polynomial using elements in the 2nd row.

    P(s)=s4+6s2+8

    Differentiating the above with respect to s, we obtain,

    dsdP(s)​=4s3+12s+0

    The coefficients of the differential are then used to replace the zeroes in the 3rd row.
    The remaining elements are formed in a straightforward manner in the standard way.

    #Stability of a Negative Feedback Control System

    Consider a control system with a negative feedback loop.

    At the summation point,

    E(s)=R(s)−B(s)

    E(s)=R(s)−H(s)⋅C(s)

    Closed-loop transfer function,

    C(s)=E(s)⋅G(s)

    C(s)=[R(s)−H(s)⋅C(s)]⋅G(s)

    C(s)=R(s)⋅G(s)−H(s)⋅G(s)⋅C(s)

    💡

    M(s)=R(s)C(s)​=1+G(s)⋅H(s)G(s)​

    If the feedback loop is positive, the sign in the denominator is “+”.

    Initial value theorem,

    💡

    f(0+)=t→0+lim​ f(t)=s→∞lim​ sF(s)

    f(t) and f′(t) must be Laplace transformable.
    Initial value must exists such that limit exists.

    Final value theorem,

    💡

    f(∞)=t→∞lim​ f(t)=s→0lim​ sF(s)

    sF(s) must have no poles on the right side of imaginary axis.
    sF(s) must have no poles lying on the imaginary axis.
    sF(s) must have no pole lying on the origin.
    Final value must exists such that limit exists.
